# Volunteer Fire Department Coordinator — Discovery Questions

Inquiry received 2026-08-19 via text: department-only calendar app — monthly events, reminders, attendee status (committed / possible / can't make it), viewable by members, editable from phone by admins.

## People & access

- [ ] How many members would use this? One department, or could other stations/departments join later?
- [ ] Who counts as an "admin" — officers only, or anyone you designate? Roughly how many admins?
- [ ] Does everyone have an iPhone, or are some members on Android? (This is a major scope/cost fork — pin it down early.)
- [ ] How should members get access — an invite code, admin adds them by name/phone, or reuse the existing FirefighterSpot roster/accounts?
- [ ] When someone leaves the department, who removes their access?

## Events

- [ ] What kinds of events go on the calendar — trainings, business meetings, fundraisers, work details, standbys, social events? Any that should be visible to only some members?
- [ ] Do you need recurring events (e.g., "monthly meeting, first Tuesday") or is each event entered individually?
- [ ] What details does an event need — date/time, location, description, required gear, attachments (flyers, agendas)?
- [ ] Can only admins create and edit events, or can any member propose one?
- [ ] When an event changes or is cancelled, how should members find out?

## Attendance status

- [ ] Is committed / possible / can't-make-it the full list of statuses, or do you also need to see who hasn't responded?
- [ ] Can members change their answer up until the event, or is there a cutoff?
- [ ] Do admins need a headcount view or roster list per event? A minimum-staffing warning ("need at least 4")?
- [ ] Do you need to record who actually attended afterward (for training records, LOSAP points, participation requirements)?
- [ ] Any reports to pull out — printable roster, attendance history per member, end-of-year totals?

## Reminders & notifications

- [ ] What reminders do you want — e.g., when an event is posted, a week before, the day before?
- [ ] Should the reminder schedule be set per event by the admin, or chosen by each member for themselves?
- [ ] Do you want a nudge sent to members who haven't responded yet?
- [ ] Any members unlikely to install an app — do you need a text/email fallback so nobody is left out?
